# Swiss Law Collection — website

The published site for the [swiss-law](https://github.com/benjamin-arfa/swiss-law) pipeline:
a dashboard over Swiss federal and cantonal legislation, plus a static read-only JSON/CSV/SDMX
API served straight from GitHub Pages.

**https://swiss-law-as-source.github.io/**

| | |
| --- | --- |
| Dashboard | [index.html](https://swiss-law-as-source.github.io/) |
| Law index | [laws.html](https://swiss-law-as-source.github.io/laws.html) |
| Data & methodology | [data.html](https://swiss-law-as-source.github.io/data.html) |
| Verification | [verification.html](https://swiss-law-as-source.github.io/verification.html) |
| API reference | [api.html](https://swiss-law-as-source.github.io/api.html) |
| Embeddable charts | [embed.html](https://swiss-law-as-source.github.io/embed.html) |

This repo holds generated output. Pages, payloads and charts are produced by the pipeline repo —
edit them there, not here. Two scripts are the exception and do live here:

```bash
python3 stamp_assets.py   # re-hash assets/ URLs after editing an asset (run before committing)
```

The shared header, footer and licence line are generated by `scripts/sync_site_nav.py` in the
pipeline repo (`--check` reports drift); do not hand-edit that markup.
