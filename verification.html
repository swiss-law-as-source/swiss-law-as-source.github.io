1. Question under verification

How far can this collection's concordat data reproduce the reference table "Concordats par domaine" (chstat.ch, 2003), which was computed by the Institute of Federalism from the same underlying source (LexFind)? This page renders live from the published data — it updates with every regeneration.

Answer in short: not fully — and the statistic does not try to. The published concordats table is computed purely from the source data: one occurrence per signing canton per agreement, signatories estimated as the cantons publishing the text ∪ the cantons named in any language version's title. No scaling, no external baseline (see below). chstat/BADAC's 2003 figure is kept as an external comparison reference; the difference is historical attrition — agreements repealed decades ago were delisted from today's collections. Filling in missing dates via the undated-laws review and importing corrections (legalize-ch import-dates) improves the statistic.

3. Methodology

  • Counting unit (headline table): signatory-canton memberships, the chstat/BADAC convention — each agreement counts once per signatory canton (an agreement signed by 10 cantons counts 10, not 1). Signatory sets for our post-2003 data are estimated per agreement: cantons publishing the text in their collections ∪ cantons named in any language version's title. Computed purely from the source data — no scaling; chstat's 2003 table is an external comparison reference only.
  • Laws are (law, version) pairs. All year filtering uses the enactment date (original act), never the current consolidated version's date. A 1970 concordat amended in 2015 counts as 1970.
  • Date provenance is ranked: lexfind_family (LexFind's family_active_since — the act's original date, from LexFind's frontend API, available for all 26 cantons) > lexwork_api (the portal's date_of_decision, authoritative but sometimes the canton's accession decision) > sibling:<CANTON> (a concordat is the same act in every member canton — dates propagate from cantons with authoritative data, only when all authoritative siblings agree) > text (parsed "vom / du / del D. Month YYYY" from the stored law text) > version_date_only. Higher provenance overwrites lower, never vice versa.
  • Repealed laws are included and flagged (is_active: false from the LexFind catalogs) — the collection is not in-force-only.
  • The accession caveat: LexWork's decision date is frequently each canton's accession decision rather than the concordat's original date — proven by sibling groups whose authoritative dates conflict across cantons. chstat counted 2003 membership, a question no public source answers directly today.
  • "Unexplained" therefore contains: concordats no longer attached to LexFind's public systematics catalogs (LexFind's own global/stats reports more texts of law than the catalogs enumerate — the detached/delisted slice), plus accession-vs-membership date semantics.
